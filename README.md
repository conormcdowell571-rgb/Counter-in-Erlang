# Overview

I wrote a program that can calculate a factorial, give the fibonacci sequence up to a given number, or double the number one until we reach the given number.

I wrote this software in order to familiarize myself with the erlang language and with many principles of it such as recursion which is used in place of loops.

[Software Demo Video](https://www.youtube.com/watch?v=T50SRMThESA)

# Development Environment

I used the vscode environment to develop this program and the erlang language.
